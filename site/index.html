ARCHITECTURAL SAFETY

Legitimate Windows APIs. Zero Game Interference.

01

Windows Magnification Color Matrix

Color saturation, vibrance, brightness, contrast, and color temperature are composed into a 4×5 color matrix via the Windows Magnification API (MagSetFullscreenColorEffect) — the exact same OS layer used by the official Windows Magnifier and color filters.

02

Direct GPU Gamma Tables

A second pipeline writes custom transfer curves directly into the GPU display lookup table with SetDeviceGammaRamp. This provides shadow lift, highlight compression, and gamma correction without touching game framebuffers or adding input lag.

03

Safe Foreground Window Monitoring

Profile auto-switching checks the frontmost window using GetForegroundWindow and QueryFullProcessImageNameW. It never injects code, never opens process handles for writing, and never touches game memory.

FREQUENTLY ASKED QUESTIONS

Everything you need to know.

Will I get banned by anti-cheat systems (BattlEye, EAC, VAC, Vanguard)?

PlexusX operates exclusively on the desktop display output pipeline (Windows Magnification API and GPU hardware gamma ramps). It does not open game process handles for memory reading or writing, does not hook DirectX/Vulkan/OpenGL, does not inject DLLs, and does not touch game files. It functions in the exact same legal domain as your GPU control panel (NVIDIA Control Panel / AMD Adrenalin) or monitor physical OSD buttons.

Does it work with NVIDIA, AMD, and Intel GPUs?

Yes. PlexusX automatically detects your GPU vendor (NVIDIA GeForce, AMD Radeon, Intel Arc / Iris) and interfaces directly with the standard Windows display APIs. It works identically across all modern GPUs.

How does the 300% Saturation Engine differ from GPU control panels?

Standard GPU control panels typically limit digital vibrance to 100% or 200%. PlexusX allows scaling up to 300% application boost, combined with smart vibrance (which protects already saturated tones), shadow lift, highlight compression, and clarity S-curves for superior target visibility.

My screen went black, or a test pattern will not close — what now?

Press Ctrl+Alt+Shift+R (Emergency Safe Reset): it closes every test pattern, bypasses the color engine and restores your display. Ctrl+Alt+0 resets all channels and tone curves to neutral. Test patterns also close by themselves after 10 seconds, and any key press or mouse click dismisses them. If PlexusX ever crashes it restores the display first and writes %LOCALAPPDATA%\PlexusX\crash.log.

How do I uninstall PlexusX?

Simply close the application (which instantly restores all gamma ramps to hardware defaults) and delete the executable. If you used the installer, run Uninstall from Windows Settings > Apps. To remove all local profiles, delete %APPDATA%\PlexusX.
